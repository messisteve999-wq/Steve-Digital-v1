# WARRIOR KING — V1

## Installation dans Termux

1. Décompressez le ZIP.
2. Entrez dans le dossier :
   cd ~/warrior_king
3. Installez les dépendances :
   npm install
4. Lancez le site :
   npm start
5. Ouvrez dans le navigateur :
   http://localhost:3000
